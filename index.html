Manual for RPEL commands

Commands: .help, .linktosource, .websource, .metasource, .freemem, .exit
.linktosource is for teleporting you to main source code
.websource is for teleporting you to the source code of our website
.metasource is where all the sources are present
.freemem is for freeing memory
.exit is to exit the appilcation (tip. you can press Ctrl+C)
